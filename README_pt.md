# EasyTask - Gerenciador de Tarefas Corporativas

![Logo do EasyTask](assets/task-management-logo.png)

EasyTask é um aplicativo de gerenciamento de tarefas projetado para equipes empresariais.

## Principais recursos

- 👤 Gerenciamento de tarefas por usuário
- 📅 Prazos com formatação clara
- ➕ Adicionar novas tarefas facilmente
- ✅ Marcar tarefas como concluídas
- 💾 Armazenamento local de dados
- 🎨 Interface limpa e responsiva

## Componentes principais

### `AppComponent`
- Componente raiz que gerencia seleção de usuários
- Exibe tarefas do usuário selecionado

### `TasksComponent`
- Lista tarefas do usuário
- Permite adicionar novas tarefas

### `TaskComponent`
- Exibe detalhes de cada tarefa
- Botão para concluir tarefas

### `UserComponent`
- Cartão de usuário selecionável
- Mostra avatar e nome

## Como usar

1. Selecione um usuário
2. Visualize suas tarefas
3. Adicione novas tarefas com o botão "+"
4. Marque tarefas como concluídas quando finalizadas

## Tecnologias

- Angular 17+
- TypeScript
- LocalStorage
