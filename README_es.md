# EasyTask - Gestor de Tareas Empresariales

![Logo de EasyTask](assets/task-management-logo.png)

EasyTask es una aplicación de gestión de tareas diseñada para equipos empresariales que permite administrar y organizar tareas de manera eficiente.

## Características principales

- 👥 Gestión de tareas por usuario
- 📆 Fechas de vencimiento con formato claro
- ➕ Añadir nuevas tareas fácilmente
- ✅ Marcar tareas como completadas
- 💾 Almacenamiento local de datos
- 🎨 Interfaz intuitiva y responsive

## Componentes principales

### `AppComponent`
- Componente principal que gestiona la selección de usuarios
- Muestra las tareas del usuario seleccionado

### `TasksComponent`
- Lista las tareas del usuario
- Permite agregar nuevas tareas

### `TaskComponent`
- Muestra detalles de cada tarea
- Botón para completar tareas

### `UserComponent`
- Tarjeta de usuario seleccionable
- Muestra avatar y nombre

## Cómo usar

1. Selecciona un usuario
2. Visualiza sus tareas pendientes
3. Añade nuevas tareas con el botón "+"
4. Marca tareas como completadas cuando las finalices

## Tecnologías

- Angular 17+
- TypeScript
- LocalStorage
